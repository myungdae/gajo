# TMAP + ChatGPT 여행계획 이의 제기 검증 가이드

## 제품 검증 원칙

**TMAP과의 차별성을 설명으로만 이해시키지 않는다. 사용자가 1~2분 사용하면 PLAN → NOW → RE-PLAN → ACTION의 차이를 경험으로 느낄 수 있어야 한다.**

이 원칙은 마케팅 문구가 아니라 향후 UX 회귀 테스트와 현장 데모 설계의 합격 기준이다. 설명 질문은 읽기 전용이며 활성 TripSession, 일정, 실행 상태, 의미 맥락, 현재 지역을 바꾸지 않는다.

## 비교 데모 흐름

1. “옥천 여행 일정 짜줘.”
2. 범용 AI도 좋은 여행 일정을 만들 수 있음을 먼저 인정한다.
3. 같은 Regional Concierge 여행에서 다음 조건을 차례로 추가한다.
   - “그런데 지금 벌써 오후 4시야.”
   - “비도 오네.”
   - “70대 어머니와 같이 왔는데 많이 못 걸으셔.”
   - “화장실부터 가야 해.”
   - “전기차 충전도 해야 하는데.”
   - “한 시간밖에 없어.”
   - “그래도 정지용 관련된 곳은 꼭 보고 싶어.”
   - “그럼 어디부터 가지?”
   - “길찾기 해줘.”

관찰 항목은 맥락 누적, 관리되는 Hyper-local Knowledge와 검토된 운영 데이터, 재계획, 여정 연속성, 안전한 길찾기 행동 연결이다. 실제 옥천 데이터가 좌표·운영 상태·접근성·이용 가능성을 뒷받침하지 않으면 성공한 일정이나 행동을 임의로 만들지 않는다.

## 역할 비교

- 범용 AI: 폭넓은 지식과 강한 언어 이해·추론·계획.
- TMAP: 장소 발견, 목적지 검색, 경로 안내, 운전과 효율적인 이동.
- Regional Concierge: 범용 AI + 관리되는 지역 지식 + 근거가 확인된 운영 데이터 + 현재 Trip Context + 여정 연속성 + 안전한 행동. 목적지를 고른 뒤에는 TMAP·네이버 지도·카카오맵과 함께 작동한다.

Regional Concierge가 항상 실시간 정보를 가지거나 모든 지역 데이터가 완전하다고 주장하지 않는다. TMAP의 추천·맥락 기능이나 ChatGPT의 재계획·위치·도구 활용 능력을 부정하지 않는다.
