# 옥천 모바일 현장 테스트 체크리스트

- [ ] QR/링크로 최신 방문자 화면을 열고 지역이 `okcheon`인지 확인한다.
- [ ] “정지용 시인과 관련된 곳을 둘러보고 옥천다운 점심도 먹고 싶어요.”를 묻는다.
- [ ] 각 장소의 포함 이유가 문화 관계/지역음식 근거로 설명되는지 확인한다.
- [ ] 전체 일정을 `내 여행에 담기`로 저장하고 `내 여행`에서 같은 순서를 확인한다.
- [ ] `출발하기` 후 현재 장소와 다음 장소가 표시되고, 승인된 장소에만 길찾기가 보이는지 확인한다.
- [ ] “정지용 관련 장소만 보여줘.”와 “시간이 한 시간밖에 없어.”로 의미 맥락이 이어지는지 확인한다.
- [ ] 옥천구읍에서 다른 옥천 위치로 이동시킨 뒤 여행 ID와 저장 일정이 유지되는지 확인한다.
- [ ] “비가 오기 시작했어요.”로 재계획하고 필수 방문지와 TripSession이 유지되는지 확인한다.
- [ ] PWA/브라우저를 닫았다 다시 열어 `내 여행 계속하기`와 실행 위치가 복원되는지 확인한다.
- [ ] “근처 편의점 있어?”, “마트는?”, “다른 데는?”를 묻고 미승인 후보가 방문자에게 노출되지 않는지 확인한다.
- [ ] 전화·길찾기가 승인된 RDM 사실에만 나타나는지 확인한다.
- [ ] 합천·가조의 저장 여행, Copilot 큐, 의미 설정에 옥천 항목이 섞이지 않는지 확인한다.
